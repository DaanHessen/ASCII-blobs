ASCII-blobs Documentation

Drop-in animated ASCII backgrounds for React and plain JavaScript. The renderer projects gaussian blobs onto a character grid, pre-renders glyph atlases, and keeps frame pacing predictable even on dense layouts.

View demo Source on GitHub

What you get

  • React component with ref controls (pause, resume, reset, stats).
  • Vanilla class for framework-free embeds.
  • Typed configuration with sane defaults and clamped values.
  • Built-in themes plus customizable colors and glyph palette.
  • Full CSS bundle (ascii-blobs/dist/style.css) and auto-injected styles in both builds.
Defaults at a glance: 8 blobs, frame interval 42 ms (~24 fps draw budget), cell size 14px, character set " .,:;!~+=xoX#".

Install

The package ships ESM + CJS builds, TypeScript defs, the vanilla bundle, and a standalone stylesheet.

npm install ascii-blobs

If you serve the bundle from a static page (without a bundler), include ascii-blobs.css and vanilla.mjs from the package.

React usage

AsciiBlobs is a plain functional component. Styles are auto-injected once per page. Use the ref to pause, resume, reset, or read stats.

import { useRef } from "react";
import { AsciiBlobs, getThemeClassName } from "ascii-blobs";
import type { AsciiBlobsRef } from "ascii-blobs";

export function Hero() {
  const blobsRef = useRef<AsciiBlobsRef | null>(null);

  return (
    <section style={{ position: "relative", minHeight: "420px" }}>
      <AsciiBlobs
        ref={blobsRef}
        className={getThemeClassName("dracula")}
        style={{ position: "absolute", inset: 0, zIndex: -1 }}
        colors={{ primary: "#BD93F9" }}
        blobBehavior={{ count: 10 }}
        onReady={() => console.log("ASCII-blobs ready")}
      />
      <div style={{ position: "relative", padding: "48px 0" }}>
        <h2>Neon console vibes</h2>
        <button onClick={() => blobsRef.current?.reset()}>Refresh blobs</button>
      </div>
    </section>
  );
}
  • Default positioning is fixed full-viewport. Override via style (as above) to scope it to a container.
  • AsciiBlobsRef methods: pause(), resume(), reset(), getStats().
  • onReady runs after the internal grid and glyph atlas are initialized. onBlobSpawn fires whenever a blob is created or recycled.

Vanilla usage (ESM)

The vanilla build ships at ascii-blobs/vanilla. It renders into a wrapper inside your container, sets position: relative and overflow: hidden if missing, and keeps an internal animation loop.

import { AsciiBlobs, getThemeClassName } from "ascii-blobs/vanilla";

const stage = document.querySelector("#stage");
const blobs = new AsciiBlobs(stage, {
  className: getThemeClassName("nord"),      // optional theme class
  style: { position: "absolute", inset: "0" },
  colors: { primary: "#88C0D0" },
  blobBehavior: { count: 6, maxRadius: 180 },
  animation: { frameInterval: 42 },          // draw budget in ms
});

// Controls
blobs.pause();
blobs.resume();
blobs.reset();
console.log(blobs.getStats()); // { blobCount, fps, isPaused }

// Cleanup
window.addEventListener("beforeunload", () => blobs.destroy());
Note: The wrapper uses position: fixed by default (from the CSS). Add a class or inline styles to change it to absolute when you want the effect confined to a specific element.

Configuration reference

All fields are optional; unspecified values fall back to the defaults below. Numeric values are clamped for safety (e.g. blob count ≥ 1, cell size ≥ 6, target FPS max 240).

Colors

FieldDefaultDescription
primaryrgb(100, 180, 255)Text color of lit glyphs.
background#000000Optional override for the backdrop gradient stops.
glowrgba(100, 180, 255, 0.8)Outer glow tint for glyph atlas.
shadowrgba(100, 180, 255, 0.4)Shadow tint for glyph atlas.

Characters

characters (default " .,:;!~+=xoX#") is mapped to brightness. The renderer jitters the palette slightly per cell for variation.

Animation

FieldDefaultDetails

revealFade400 msPer-cell fade-in after its delay.

Performance

FieldDefaultDetails
cellSize14 pxGrid resolution; lower = sharper, heavier.

Other props

  • className: appended to the wrapper (themes plug in here).
  • style: inline styles merged onto the wrapper (useful to override positioning/z-index).
  • onReady: called after canvases, grid, and glyph atlas are initialized.
  • onBlobSpawn: called whenever a blob is created or recycled.
  • interactive: present in the type but currently unused by the renderer.

API

React

<AsciiBlobs />

  • Props: any AsciiBlobsConfig fields + className/style.
  • CSS is injected automatically on first import.
  • Unmounting cleans up animation frames and resize listeners.

Ref (AsciiBlobsRef)

  • pause() / resume()
  • reset(): respawns all blobs and restarts the reveal animation.
  • getStats(): returns { blobCount, fps, isPaused }.
Vanilla

new AsciiBlobs(container, config?)

  • container can be an element or selector string.
  • CSS is injected automatically; the wrapper is appended to the container.
  • destroy() tears down the canvases, listeners, and DOM.
  • Other methods mirror the React ref: pause, resume, reset, getStats.
Advanced exports

Core helpers

  • mergeConfig, defaultConfig
  • createBlob, resetBlob, updateBlob, pickSpawnPoint
  • setupGrid, drawFrame, pickShadeIndex
  • gaussianFalloff, createGaussianSampler
  • Constants: CELL_SIZE, ASCII_PALETTE, GAUSSIAN_LUT_SIZE, etc.

These are surfaced for customization; the renderer uses the same functions internally.

Themes and styling

Theme class names are exported via themes and getThemeClassName(ThemeName). Apply them through className (React) or className in the config (vanilla). Available theme keys:

default catppuccin-mocha catppuccin-latte dracula nord gruvbox tokyo-night

Set colors.background to retint the base gradient quickly. For deeper tweaks (accent layers, texture, vignette), add your own CSS targeting the wrapper class.

Performance tips

  • Lower blobBehavior.count or raise animation.frameInterval for slower devices.
  • cellSize has the biggest cost impact: smaller cells brighten detail but increase draw calls.
  • useOffscreenCanvas and enableBlur are on by default; disable blur if you prefer crisper glyph edges.
  • The renderer debounces resize work (180 ms) and caps delta time at 120 ms to avoid spikes.
  • If a warmed start is desired, call reset() to refresh blob lifetimes without tearing down the instance.
