ASCII-blobs

Animated ASCII metaballs for the web

A lightweight renderer that turns gaussian metaballs into animated ASCII art. Ships as both a React component and a vanilla JavaScript class, drawing on layered canvases with glow, texture, and vignette effects.

  • Version: 1.0.4
  • License: MIT
  • Author: Daan Hessen
  • Repository: github.com/DaanHessen/ASCII-blobs
  • Demo: daanhessen.github.io/ASCII-blobs

CSS is auto-injected once per page via ensureAsciiBlobsStyles. If you load the prebuilt bundle directly from a CDN without bundling, include dist/ascii-blobs.css manually.

Installation

Install from npm. React is optional unless you use the React component.

  1. Install the package: 
    npm install ascii-blobs
  2. Use the React component or the vanilla class (examples below). No extra CSS import is required when bundling.

Optional peer dependencies (React build only): react, react-dom.

Package Layout

Entry points exposed via package.json#exports:

Entry Import Purpose
React import { AsciiBlobs } from 'ascii-blobs' Viewport-filling React component.
Vanilla import { AsciiBlobs } from 'ascii-blobs/vanilla' Class-based API that attaches to any element.
Stylesheet import 'ascii-blobs/dist/ascii-blobs.css' Manual CSS include when not bundling.
Utils/Types import { mergeConfig, themes, createBlob, ... } from 'ascii-blobs' Helper functions, constants, and types.

Runtime Notes

  • Requires browser APIs: window, document, CanvasRenderingContext2D, requestAnimationFrame.
  • Uses OffscreenCanvas when available; falls back automatically otherwise.
  • React build: fixed-position, full-viewport, pointer-events: none so it stays behind your UI.
  • Vanilla build: wrapper uses the same fixed/inset CSS by default; override style or your CSS if you want it scoped to a container.
  • Not SSR-safe by itself; load only in the browser (e.g., dynamic import on the client).

Usage

React and vanilla APIs share the same AsciiBlobsConfig.

React

Place the component near the top of your tree so it renders behind content.

import { useEffect, useRef } from 'react';
import { AsciiBlobs, type AsciiBlobsRef } from 'ascii-blobs';

export function HeroBackground() {
  const blobsRef = useRef<AsciiBlobsRef>(null);

  useEffect(() => {
    const id = setInterval(() => console.log(blobsRef.current?.getStats()), 2000);
    return () => clearInterval(id);
  }, []);

  return (
    <AsciiBlobs
      ref={blobsRef}
      colors={{ primary: '#7dd3fc', background: '#050814' }}
      blobBehavior={{ count: 10 }}
      animation={{ frameInterval: 32 }}
      className="ascii-blobs--theme-dracula"
    />
  );
}
  • CSS is injected automatically; no manual stylesheet import needed when bundling.
  • className appends classes to the root .ascii-blobs element (use for themes).
  • style is merged with CSS variables if you supply colors.*.

Vanilla JavaScript

Attach to any element or selector. Pointer events are disabled; default z-index is -1 unless overridden via style.

import { AsciiBlobs } from 'ascii-blobs/vanilla';

const ascii = new AsciiBlobs('#hero', {
  colors: { primary: '#8b5cf6', background: '#0b1021' },
  blobBehavior: { count: 6, maxSpeed: 10 },
  animation: { revealDuration: 1400 },
});

ascii.pause();
ascii.resume();
ascii.reset();
console.log(ascii.getStats());
ascii.destroy();

If the container lacks positioning/overflow styles, the class will set position: relative, overflow: hidden, and isolation: isolate. Override .ascii-blobs positioning (or pass style) to scope it to the container instead of viewport-fixed.

Refs & Controls

  • pause() — stop updates/renders.
  • resume() — restart animation and timestamps.
  • reset() — respawn blobs and restart the reveal.
  • getStats() — returns { blobCount, fps, isPaused }.
  • destroy() — (vanilla only) remove canvases/listeners from the container.

Configuration

All options are merged with defaultConfig via mergeConfig, with clamping to safe ranges.

Colors & Characters

Colors become CSS variables used by gradients, glow, and shadow. Characters are jittered per atlas for organic variation.

Field Default Description
colors.primary rgb(100, 180, 255) Base glyph color.
colors.background #000000 Overrides --ascii-bg-base/mid/dark when set.
colors.glow rgba(100, 180, 255, 0.8) Outer glow (baked into glyph atlas).
colors.shadow rgba(100, 180, 255, 0.4) Inner shadow (baked into glyph atlas).
characters ' .,:;!~+=xoX#' Ordered darkest → brightest.

CSS variables you may override: --ascii-primary, --ascii-bg-base, --ascii-bg-mid, --ascii-bg-dark, --ascii-glow, --ascii-shadow, --ascii-accent-1/2, --ascii-backdrop-1..6, --ascii-texture-1..3, --ascii-vignette-start/end.

Blob Behavior

Speeds and radii are remapped relative to defaults and scaled to viewport size to stay proportional.

Field Default Notes
blobBehavior.count 8 Number of active blobs (min 1).
blobBehavior.minSpeed / maxSpeed 6 / 12 Relative speed samples; clamped to ≥0 and remapped internally.
blobBehavior.minRadius / maxRadius 60 / 140 Radius samples before remapping; max ≥ min.
blobBehavior.spawnInterval 3000 ms Controls life variance and warm-start offset.
blobBehavior.lifespan 30000 ms Min is fadeInDuration + 500.
blobBehavior.fadeInDuration 2000 ms Per-blob envelope ramp.
wobbleAmplitude 0.15 Scale variation multiplier.
wobbleSpeed 0.0004 Frequency multiplier (ms-based).
rotationSpeed 0.00003 Radians/ms (randomized positive/negative).

Animation

Field Default Description
animation.frameInterval 42 ms Min time between draws (≈24 FPS). If omitted and performance.targetFPS is set, derived from that (min 5 ms).
animation.revealDuration 1200 ms Length of initial fade-in.
animation.revealFade 400 ms Per-cell reveal offset; each cell delays between -0.65 × revealFade and revealDuration.

Performance

Field Default Notes
performance.cellSize 14 Character cell size in px (min 6). Bigger = fewer cells.
performance.gaussianLutSize 1024 LUT resolution for gaussian falloff (min 32).
performance.targetFPS 60 Used only when animation.frameInterval is omitted; clamped 1–240.
performance.useOffscreenCanvas true Uses OffscreenCanvas for glyph atlases when supported.
performance.enableBlur true Enables glow/shadow blur when drawing glyphs.

Lower load by increasing cellSize, reducing blobBehavior.count, disabling enableBlur, or raising frameInterval.

Callbacks

  • onReady?: () => void — fired after initial setup.
  • onBlobSpawn?: (blob) — fired whenever a blob is spawned or respawned.

interactive?: boolean is present for future use and currently unused.

API

Main exports plus core utilities.

Exports

  • AsciiBlobs React component and AsciiBlobsRef.
  • AsciiBlobs class from ascii-blobs/vanilla.
  • Types: AsciiBlobsConfig, ColorConfig, BlobBehaviorConfig, AnimationConfig, PerformanceConfig, MergedConfig, CloudBlob, State, BlobTempBuffers.
  • Constants: CELL_SIZE, HALF_CELL, FRAME_INTERVAL, REVEAL_DURATION, REVEAL_FADE, WRAP_MARGIN, SPAWN_MARGIN, INTERIOR_MIN, INTERIOR_MAX, ASCII_PALETTE, CANVAS_FONT, FONT_FAMILY, OVERLAY_RGB, ALPHA_EPSILON, GAUSSIAN_LUT_SIZE, GAUSSIAN_LUT_MAX, GAUSSIAN_SCALE.
  • Themes: themes map, getThemeClassName(themeName).
  • Config helpers: defaultConfig, mergeConfig(userConfig).

Utility Functions

  • createBlob, resetBlob, updateBlob, pickSpawnPoint, randomBetween, clamp — blob lifecycle helpers.
  • setupGrid — builds the cell grid and noise buffers.
  • drawFrame, pickShadeIndex — renderer building the ASCII overlay.
  • createGlyphAtlas — prerenders glyphs with glow/shadow using canvas or OffscreenCanvas.
  • gaussianFalloff, gaussianLUT, createGaussianSampler — gaussian utilities used by the renderer.

FAQ

Do I need to import CSS manually?
Bundled usage auto-injects AsciiBlobs.css exactly once via ensureAsciiBlobsStyles. If you consume the prebuilt ES/CJS bundle directly without bundling, include dist/ascii-blobs.css yourself.
How do I keep it behind my UI?
React build is fixed, full-viewport, and uses pointer-events: none. Vanilla build defaults to the same, with z-index: -1 unless overridden. Override style or CSS if you need a scoped container.
How can I reduce CPU/GPU usage?
Increase performance.cellSize, reduce blobBehavior.count, disable performance.enableBlur, or raise animation.frameInterval.
Is it SSR safe?
No. It requires window, document, and canvas. Load only in the browser (e.g., dynamic import on client).
