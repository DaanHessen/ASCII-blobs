ASCII Blobs
Demo GitHub NPM

Documentation

Complete API reference for ascii-blobs, a library for creating beautiful animated ASCII blob backgrounds using gaussian metaball rendering.

Installation

npm install ascii-blobs

Quick Start

React

import { AsciiBlobs } from 'ascii-blobs';
import 'ascii-blobs/dist/style.css';

function App() {
  return <AsciiBlobs />;
}

Vanilla JavaScript

import { AsciiBlobs } from 'ascii-blobs/vanilla';
import 'ascii-blobs/dist/style.css';

const blobs = new AsciiBlobs('#container');

Configuration

Both the React component and vanilla JavaScript class accept a configuration object. All properties are optional and fall back to sensible defaults.

AsciiBlobsConfig

Top-Level Options

characters
Type: string
Default: " .,:;!~+=xoX#"
Ordered string of glyphs from darkest (space) to brightest. The renderer picks characters based on the computed brightness at each cell. You can pass custom character sets like " ░▒▓█" for block characters or " .oO@" for simple dots.
className
Type: string
Default: undefined
Additional CSS classes to append to the wrapper element. Use with getThemeClassName() for built-in themes or your own utility classes.
style
Type: React.CSSProperties
Default: undefined
Inline styles merged onto the wrapper. CSS custom properties you provide here override the generated variables. The component defaults to position: fixed and z-index: 0.
onReady
Type: () => void
Default: undefined
Callback invoked once after canvases are mounted and the first render is scheduled.
onBlobSpawn
Type: (blob: CloudBlob) => void
Default: undefined
Called with each newly spawned blob. Useful for analytics or syncing other visuals.
interactive
Type: boolean
Default: undefined
Reserved flag for upcoming pointer controls (currently unused).

colors

Type: ColorConfig

primary
Type: string
Default: "rgb(100, 180, 255)"
Main color for ASCII glyphs. Accepts any valid CSS color.
background
Type: string
Default: "#000000"
Backdrop gradient base color. Sets CSS variables --ascii-bg-*.
glow
Type: string
Default: "rgba(100, 180, 255, 0.8)"
Outer glow tint drawn behind glyphs when blur is enabled.
shadow
Type: string
Default: "rgba(100, 180, 255, 0.4)"
Inner shadow tint that adds depth to characters when blur is enabled.

blobBehavior

Type: BlobBehaviorConfig

count
Type: number
Default: 8
Number of simultaneous blobs. More blobs = more complex patterns but higher CPU usage.
minSpeed / maxSpeed
Type: number
Default: 6 / 12
Speed range in grid cells per second. Each blob picks a random speed in this range.
minRadius / maxRadius
Type: number
Default: 60 / 140
Blob radius range in grid cells. Higher values = softer, larger blobs with more gradual falloff.
spawnInterval
Type: number
Default: 3000 (ms)
Time between spawning new blobs. Set to 0 to disable interval-based spawning.
lifespan
Type: number
Default: 30000 (ms)
Maximum blob lifetime. Automatically clamped to stay above fadeInDuration + 500.
fadeInDuration
Type: number
Default: 2000 (ms)
Ramp-up time before a blob becomes fully visible.
wobbleAmplitude
Type: number
Default: 0.15
Scale of organic wobble (0-1). Higher values = more pronounced pulsing.
wobbleSpeed
Type: number
Default: 0.0004
Rate of wobble animation. Higher values = faster pulsing.
rotationSpeed
Type: number
Default: 0.00003
Base angular velocity for blob rotation (radians per millisecond).

animation

Type: AnimationConfig

frameInterval
Type: number
Default: 42 (ms)
Minimum time between frame draws. Leave undefined to derive from performance.targetFPS.
revealDuration
Type: number
Default: 1200 (ms)
Duration of initial reveal animation across the grid.
revealFade
Type: number
Default: 400 (ms)
Delay variance for each cell before it starts revealing.

performance

Type: PerformanceConfig

cellSize
Type: number
Default: 14 (pixels)
Pixel size of each grid cell. Lower values increase fidelity but require more computation. Minimum: 6.
gaussianLutSize
Type: number
Default: 1024
Precision of Gaussian lookup table. Higher = more accurate falloff but uses more memory. Minimum: 32.
targetFPS
Type: number
Default: 60
Desired frame rate. Used when frameInterval is not explicitly set. Range: 1-240.
useOffscreenCanvas
Type: boolean
Default: true
Use OffscreenCanvas for glyph atlas rendering when supported by the browser.
enableBlur
Type: boolean
Default: true
Toggle glow/shadow blur passes. Disable on lower-power devices for better performance.

React API

Component

import { AsciiBlobs } from 'ascii-blobs';
import type { AsciiBlobsRef } from 'ascii-blobs';

<AsciiBlobs
  characters=" .,:;!~+=xoX#"
  colors={{ primary: 'rgb(100, 180, 255)' }}
  blobBehavior={{ count: 8 }}
  animation={{ frameInterval: 42 }}
  performance={{ cellSize: 14 }}
  className="custom-class"
  style={{ zIndex: -1 }}
  onReady={() => console.log('Ready!')}
  onBlobSpawn={(blob) => console.log('Spawned:', blob)}
/>

Ref Methods

Access imperative controls via ref:

import { useRef } from 'react';
import { AsciiBlobs } from 'ascii-blobs';
import type { AsciiBlobsRef } from 'ascii-blobs';

function App() {
  const ref = useRef<AsciiBlobsRef>(null);

  return (
    <>
      <AsciiBlobs ref={ref} />
      <button onClick={() => ref.current?.pause()}>Pause</button>
      <button onClick={() => ref.current?.resume()}>Resume</button>
      <button onClick={() => ref.current?.reset()}>Reset</button>
    </>
  );
}

pause()

Stops the animation loop without destroying state.

resume()

Resumes the animation loop after being paused.

reset()

Respawns all blobs and restarts the reveal animation.

getStats()

Returns current statistics:

const stats = ref.current?.getStats();
// { blobCount: 8, fps: 60, isPaused: false }

Vanilla JavaScript API

Constructor

import { AsciiBlobs } from 'ascii-blobs/vanilla';

const blobs = new AsciiBlobs(
  '#container',  // selector or HTMLElement
  {
    colors: { primary: 'rgb(100, 180, 255)' },
    blobBehavior: { count: 8 },
    // ... other config options
  }
);
Note: The container element must exist in the DOM before instantiation. The library will automatically set position: relative and overflow: hidden on the container if needed.

Methods

pause()

blobs.pause();

Stops the animation loop without destroying state.

resume()

blobs.resume();

Resumes the animation loop after being paused.

reset()

blobs.reset();

Respawns all blobs and restarts the reveal animation.

getStats()

const stats = blobs.getStats();
// { blobCount: 8, fps: 60, isPaused: false }

Returns current statistics including blob count, FPS, and pause state.

destroy()

blobs.destroy();

Tears down the instance, cancels animation, removes event listeners, and clears the container.

Important: Always call destroy() when removing the component to prevent memory leaks.

Theme Function

getThemeClassName(theme)

Returns the appropriate CSS class name for the specified theme.

  • Parameters: theme: ThemeName - One of the available theme names
  • Returns: string - CSS class name(s)

TypeScript Types

CloudBlob

Represents a single blob entity with physics and animation properties.

type CloudBlob = {
  cx: number;                // Current X center position
  cy: number;                // Current Y center position
  baseRadiusX: number;       // Base radius along X axis
  baseRadiusY: number;       // Base radius along Y axis
  rotation: number;          // Current rotation angle (radians)
  rotationSpeed: number;     // Angular velocity (radians/frame)
  intensity: number;         // Brightness/opacity (0-1)
  velocityX: number;         // Horizontal velocity
  velocityY: number;         // Vertical velocity
  wobbleAmplitude: number;   // Max size variation during pulsing
  wobbleSpeed: number;       // Frequency of pulsing
  wobblePhase: number;       // Phase offset for variation
  life: number;              // Remaining lifetime (ms)
  maxLife: number;           // Total lifespan (ms)
};

State

Internal render state containing grid data and blobs.

type State = {
  columns: number;              // Grid columns
  rows: number;                 // Grid rows
  gridOffsetX: number;          // X offset of grid origin
  gridOffsetY: number;          // Y offset of grid origin
  cellCount: number;            // Total cells
  cellCentersX: Float32Array;   // X coords of cell centers
  cellCentersY: Float32Array;   // Y coords of cell centers
  cellColumns: Float32Array;    // Column index per cell
  cellRows: Float32Array;       // Row index per cell
  baseBrightness: Float32Array; // Base brightness per cell
  noiseJitter: Float32Array;    // Random variation
  noisePaletteBias: Float32Array; // Character selection bias
  revealDelays: Float32Array;   // Initial reveal delays
  glyphs: (CanvasImageSource | null)[]; // Pre-rendered sprites
  blobs: CloudBlob[];           // Active blobs
};

Advanced Usage

Custom Character Sets

// Block characters
<AsciiBlobs characters=" ░▒▓█" />

// Dots and circles
<AsciiBlobs characters=" .oO●" />

// Custom artistic set
<AsciiBlobs characters=" .-+*%@#" />

Performance Tuning

For lower-powered devices:

<AsciiBlobs
  performance={{
    cellSize: 20,           // Larger cells = fewer calculations
    targetFPS: 30,          // Lower frame rate
    enableBlur: false,      // Disable blur effects
    gaussianLutSize: 512,   // Smaller LUT
  }}
  blobBehavior={{
    count: 4,               // Fewer blobs
  }}
/>

High Fidelity

For powerful systems:

<AsciiBlobs
  performance={{
    cellSize: 8,            // Smaller cells = more detail
    targetFPS: 60,
    gaussianLutSize: 2048,  // Higher precision
  }}
  blobBehavior={{
    count: 12,              // More blobs
    minRadius: 80,
    maxRadius: 200,
  }}
/>

Lifecycle Callbacks

const [ready, setReady] = useState(false);
const [spawnCount, setSpawnCount] = useState(0);

<AsciiBlobs
  onReady={() => {
    console.log('Blobs initialized!');
    setReady(true);
  }}
  onBlobSpawn={(blob) => {
    console.log('New blob:', blob);
    setSpawnCount(c => c + 1);
  }}
/>

Responsive Sizing

The library automatically handles window resizing. For container-based sizing in vanilla JS:

const container = document.querySelector('#container');
const observer = new ResizeObserver(() => {
  // Re-initialization is automatic on window resize
  // Container resizes require manual handling
});
observer.observe(container);

FAQ

Why are my blobs not visible?

Ensure you've imported the CSS:

import 'ascii-blobs/dist/style.css';

How do I make blobs move faster?

Increase the speed range in blobBehavior:

blobBehavior={{ minSpeed: 15, maxSpeed: 25 }}

Can I use this with Next.js?

Yes! The React component works with Next.js. For SSR compatibility, ensure the component only renders on the client:

import dynamic from 'next/dynamic';

const AsciiBlobs = dynamic(
  () => import('ascii-blobs').then(mod => mod.AsciiBlobs),
  { ssr: false }
);

How do I reduce CPU usage?

See the Performance Tuning section for optimization tips.

Can I use custom fonts?

The library uses a monospace font by default. Custom fonts are not currently supported as character spacing consistency is critical for the effect.
